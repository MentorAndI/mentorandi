# Compliance workstream

The canonical U.S. AI / mental-health application compliance backlog is:

- `docs/COMPLIANCE_APP_TASKS.md`

Treat that file as a release-gate companion to `docs/CODEX_TASKS.md`, `docs/PROJECT_STATUS.md` and `docs/ARCHITECTURE.md` whenever a task touches mentor runtime behavior, onboarding/signup, AI identity, safety handling, health-related data, tracking/analytics, or U.S. launch availability.

Do not strengthen public legal or AI Safety claims before the corresponding application behavior has shipped and been verified.
