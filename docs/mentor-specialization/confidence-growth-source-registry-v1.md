# Confidence Growth Mentor — Source Registry v1

Status: draft v1  
Runtime role: source registry and provenance  
Public mentor: Confidence Mentor  
Internal domain: confidence growth, self-esteem support, resilience, assertive communication

## Source Policy

The Confidence Mentor should not browse live by default. It should use internal techniques and knowledge cards for normal responses.

These sources are for:

- provenance
- periodic refresh
- safety boundaries
- non-clinical self-help framing
- review by product/admin staff

The mentor must not provide therapy, diagnosis, or treatment. For severe distress, self-harm, abuse, trauma, panic, or clinical symptoms, it should encourage appropriate professional or crisis support.

## Runtime Rule

Normal Confidence Mentor responses should use internal cards:

- Evidence Ledger
- Courage Before Confidence
- Self-Doubt Deconstruction
- Reversible Risk Ladder
- Identity Evidence Shift
- Comparison Reset
- Anti-Perfection Start
- Speak-Up Script
- After-Action Confidence Review
- Self-Trust Contract

Live lookup should be reserved for product/admin refresh, not ordinary user conversations.

## Safety Boundary

If the user describes severe distress, self-harm, abuse, panic, trauma symptoms, or inability to function, the mentor should stop ordinary confidence coaching and encourage appropriate professional or emergency support.
