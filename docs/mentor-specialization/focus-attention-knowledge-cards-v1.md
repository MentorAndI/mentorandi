# Focus Attention Mentor — Knowledge Cards v1

## Purpose

These knowledge cards support the Focus Mentor. They provide compact principles for attention, distraction, deep work, environment design, and focus recovery.

The mentor should use these cards to improve response quality without sending long documents or doing live lookup during ordinary conversations.

## Card 1: Focus needs a target

A user cannot focus well on a vague intention. Focus improves when the task has a concrete visible target.

Use when:
- the user says "I need to focus"
- the user feels scattered
- the task is undefined

Mentor principle:
"Focus is easier when the brain knows exactly what it is protecting."

## Card 2: Distraction is often environmental, not moral

Distraction is not always a character problem. Notifications, tabs, noise, visual clutter, and open loops can continuously pull attention.

Use when:
- the user blames themselves for being distracted
- the environment is noisy
- the user has many digital inputs open

Mentor principle:
"We can reduce the number of things competing for your attention before asking you to concentrate harder."

## Card 3: Context switching has a cost

Switching between tasks creates cognitive re-entry costs. The user may lose the thread and need time to rebuild context.

Use when:
- the user jumps between tasks
- the user checks messages during work
- the user struggles to resume

Mentor principle:
"The switch is not free. Let us protect one thread long enough for it to become usable."

## Card 4: Short blocks can beat long intentions

A long focus goal may create avoidance. Short protected blocks can create movement and reduce resistance.

Use when:
- the user avoids starting
- the user has low energy
- the user feels intimidated by a long work session

Mentor principle:
"Ten protected minutes are better than a perfect three-hour plan that never starts."

## Card 5: Attention needs re-entry points

If the user stops without a restart note, returning later becomes harder. A small continuation point reduces restart friction.

Use when:
- the user often stops and cannot resume
- the user is interrupted
- the user works in multiple sessions

Mentor principle:
"End the session by making the next session easier."

## Card 6: Planning can become a focus substitute

Planning can help, but it can also become avoidance when the user keeps redesigning the system instead of starting the work.

Use when:
- the user keeps changing apps or methods
- the user asks for a perfect focus system
- the user has not begun the actual task

Mentor principle:
"The plan should be just enough to start the next visible action."

## Card 7: Research can become input overload

Opening more sources can feel productive while delaying output. Focus improves when the user turns one input into one output before collecting more.

Use when:
- the user is researching endlessly
- the user has many tabs open
- the user has not produced anything yet

Mentor principle:
"One input should become one output before the next input is added."

## Card 8: Mind wandering needs a return path

The goal is not to never drift. The goal is to notice drifting and return gently to the target.

Use when:
- the user says their mind wanders
- the user feels frustrated by distraction
- the user has difficulty sustaining attention

Mentor principle:
"A wandering mind is not failure. The skill is returning."

## Card 9: Focus is protected by boundaries

Focus time often requires boundaries with devices, people, and expectations. Boundaries can be short, clear, and kind.

Use when:
- the user is frequently interrupted
- the user feels guilty protecting time
- the user needs a communication script

Mentor principle:
"A short boundary can protect the work without creating drama."

## Card 10: Energy affects attention

Focus is harder when the user is tired, hungry, stressed, or overloaded. The mentor should not treat all focus problems as discipline problems.

Use when:
- the user is exhausted
- the user has been pushing for hours
- the user reports stress or low capacity

Mentor principle:
"Attention is partly a capacity issue. Sometimes the next best step is to reduce load or reset energy."

## Card 11: The environment should cue the task

Visible cues can make the right task easier to enter. Too many cues create competition.

Use when:
- the user’s workspace is noisy
- the user forgets what they intended to do
- the user starts the wrong task

Mentor principle:
"Your environment should point at the task, not at ten alternatives."

## Card 12: Focus improves through repeatable rituals

A small repeatable start ritual reduces decision load and makes focus easier to enter over time.

Use when:
- the user does not know how to begin
- the user wastes time choosing a method
- the user wants a routine

Mentor principle:
"The fewer decisions before focus, the more attention remains for the work."

## Runtime guidance

Use two to four cards per answer at most. Do not include all cards in the model prompt. Select cards based on the user’s current pattern: vague target, distraction, switching, interruption, re-entry, planning avoidance, or low capacity.
