# Focus Attention Mentor — Source Registry v1

## Purpose

This source registry provides provenance and refresh targets for Focus Mentor content.

The Focus Mentor should not browse live sources during ordinary conversations. It should primarily use internal techniques and knowledge cards. These URLs are for curation, safety, and periodic refresh.

## Source 1: NHS — Mindfulness

URL: https://www.nhs.uk/mental-health/self-help/tips-and-support/mindfulness/

Authority: public health guidance

Use for:
- present-moment attention framing
- gentle attention return language
- non-clinical wellbeing support

Do not use for:
- diagnosis
- promising treatment outcomes
- replacing clinical care

Summary:
NHS describes mindfulness as paying attention to thoughts, sounds, breathing, body sensations, and returning attention when the mind wanders. Use as a safe basis for attention-return language.

Refresh interval: quarterly

## Source 2: NHS Every Mind Matters — What is mindfulness?

URL: https://www.nhs.uk/every-mind-matters/mental-wellbeing-tips/what-is-mindfulness/

Authority: public health wellbeing resource

Use for:
- everyday attention practices
- sensory grounding
- reducing worry loops

Do not use for:
- mental health diagnosis
- medical claims

This source frames mindfulness as paying attention to the present and the physical world rather than being absorbed by worries. Useful for simple focus resets.

## Source 3: Mind — About mindfulness

## Source 4: Cal Newport — Deep Work

URL: https://calnewport.com/deep-work-rules-for-focused-success-in-a-distracted-world/

Authority: author/source for deep work concept

Use for:
- deep work framing
- distraction-free concentration
- focus blocks
- attention protection language

Do not use for:
- health claims
- universal life advice
- shaming users whose roles require interruptions

Summary:
Newport defines deep work as focusing without distraction on cognitively demanding tasks. Use for focus-protection and deep-work concepts, but adapt to the user’s life and avoid implying uninterrupted work is always possible.

Refresh interval: semiannual

## Source 5: Task switching and interruption research — software development example

URL: https://arxiv.org/abs/1805.05508

Authority: academic preprint

Use for:
- context switching cost
- interruption recovery
- restart notes

Do not use for:
- broad clinical attention claims
- exact productivity guarantees

Summary:
This paper discusses task interruptions and how switching can impose cognitive load and reduce focus. Use cautiously as supporting rationale for re-entry notes and single-thread focus.

Refresh interval: annual

## Source 6: Multitasking across industry projects

URL: https://arxiv.org/abs/2006.12636

Authority: academic preprint

Use for:
- context switching framing
- multitasking caution
- focus on fewer threads

Do not use for:
- medical claims
- generalizing too strongly beyond work/project contexts

Summary:
The study discusses multitasking, context switching, and productivity patterns in development work. Use as a background reference for the idea that frequent switching can make task re-entry harder.

Refresh interval: annual

## Source usage rule

Sources are not runtime prompts by default. Runtime should select compact internal cards first:

- one or two techniques
- two to four knowledge cards
- one safety boundary if needed
- relevant user memory

Live source lookup should only be used for product-maintenance refresh or when explicitly needed by an admin workflow.
